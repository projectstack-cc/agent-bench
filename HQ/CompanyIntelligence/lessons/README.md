domain, not one growing file), so the Librarian's compaction pass can work
on one slice at a time. Nothing here yet: the two real lessons this
company already has (don't trust a dispatched agent's self-report; a
suggested fix is a hypothesis, not verified ground truth) are written
directly into `agent-qa-critic.md` and `agent-ceo.md` rather than
duplicated here — see `HQ/CompanyIntelligence/success-history.md` and
`failure-history.md` for the incidents they came from.

This directory exists for lessons that don't map cleanly onto a single
executive's own file — cross-cutting patterns discovered across multiple
Debriefs. Populate only through the Debrief Gate (`agent-librarian.md`),
never directly.
